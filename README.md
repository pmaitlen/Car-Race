# Car Race Game 🏎️🏁

An interactive JavaScript car racing game with animated movement, a finish line, winner effects, and confetti celebration.

## 🎮 Live Demo
👉 https://pmaitlen.github.io/Car-Race/

## ✨ Features
- Randomized car movement
- Start / Pause / Reset controls
- Finish line detection
- Winner highlight animation
- Confetti celebration effect
- Responsive layout with CSS styling

## 🛠️ Tech Used
- HTML
- CSS
- JavaScript (DOM manipulation, timers, animation)

## 📌 Notes
This project was built as a learning exercise and later refined for portfolio presentation.
